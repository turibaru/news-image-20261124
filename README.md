## Render

Build-time only: `python3 render.py` renders `entry.png` (1024×1024, deterministic — two runs are byte-identical). The entrypoint `main.ts` (Node 22, standard library only) simply copies the committed `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`.
